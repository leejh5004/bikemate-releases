# 바이크메이트 설치 파일

프라이빗 라이더 클럽 앱입니다. 초대 코드가 있어야 가입할 수 있습니다.

## 설치

아래 주소로 APK를 받아 설치하세요. 항상 최신 버전을 가리킵니다.

```
https://github.com/leejh5004/bikemate-releases/releases/latest/download/bikemate.apk
```

## 설치가 안 될 때

- **"출처를 알 수 없는 앱"** — 크롬이나 파일 앱에 설치 권한을 한 번 허용해 주세요.
- **삼성 갤럭시** — 설정 → 보안 및 개인정보 보호 → **자동 차단** 을 꺼 주세요. 스토어를 거치지 않은 앱 설치를 막습니다.
- **설치가 거부됨** — 64비트(arm64) 기기 전용입니다. 2017년 이후 안드로이드폰이면 대부분 됩니다.

앱을 깐 뒤에는 앱 안에서 새 버전을 알려 주므로, 이 주소를 다시 찾을 일은 없습니다.
